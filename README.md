1. Project Title 
Life Dashboard 

2. Project Overview 
Life Dashboard is a web-based productivity application designed to help students and working 
professionals manage their daily tasks, stay focused, calculate quick utilities, organize notes, 
and maintain a healthy study–work routine. With background changer feature, focus features, and 
smart tools, it aims to build a personalized and distraction-free workspace for users. 

3. Objectives 
• To create an all-in-one personal dashboard for planning, writing, focusing, and quick 
calculations. 
• To support healthy productivity habits through timers, reminders, and mood-based 
interface changes. 
• To provide an easy, secure, and permanent data experience using local storage (no login 
database required). 
• To offer simple, interactive tools that save time and allow users to focus on work/study. 

4. Target Users 
• University students 
• Office workers & professionals 
• Freelancers and self-learners 
• Anyone who wants to organize daily tasks and stay focused 

5. Key Features 
• Local storage–based auto saving (data never lost) 
• Personalized greeting with user’s name 
• Mood-based visual themes 
• Quick calculator & essential tools 
• Focus Mode with background music 
• Sticky and long notes with search & formatting 
• To-Do List with priority, deadlines, and categories

6. Technologies Used 
• Front-end: HTML, CSS, JavaScript 
• Data Storage: Browser Local Storage
